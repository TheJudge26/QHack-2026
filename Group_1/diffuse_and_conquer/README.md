# Challenge: Diffuse and Conquer (400 pts)

## 1. Problem Overview
We solve a 1D diffusion-reaction equation discretized with finite differences and backward Euler time stepping:
$$A \phi_{\text{new}} = b$$
where:
* $b = \phi_{\text{old}} + \Delta t \cdot s$
* $A = (1 + k \Delta t)I - \nu \Delta t D_2$
* $D_2 = \frac{1}{h^2} \begin{pmatrix} -2 & 1 & 0 & 0 \\ 1 & -2 & 1 & 0 \\ 0 & 1 & -2 & 1 \\ 0 & 0 & 1 & -2 \end{pmatrix}$

We implement $A^{-1} b$ using **Quantum Singular Value Transformation (QSVT)**.

---

## 2. Quantum Singular Value Transformation (QSVT) Architecture

### Matrix Inversion via QSVT
To invert a matrix $A$ block-encoded in a unitary $U(A)$, QSVT applies a polynomial approximation $P(x) \approx C / x$.

1. **Polynomial Approximation**:
   Using `pyqsp.poly.PolyOneOverX`, we construct a bounded odd polynomial of degree 27 that approximates $C / x$ over the relevant condition number range $\kappa \approx 2.5$, with scale factor $C = 0.2840795$.
2. **Phase Angles $\phi_{\text{qsvt}}$**:
   The QSP phase angles $\phi_{\text{qsp}}$ generated by `pyqsp` are converted to the PennyLane QSVT convention via `qp.transform_angles(phis, 'QSP', 'QSVT')`.
3. **Block Encoding & Projectors**:
   * Target vector $|b\rangle$ lives in 2 qubits (`wires=[2, 3]`).
   * $A$ is block-encoded using 3 qubits (`wires=[1, 2, 3]`).
   * Projectors are defined using `qp.PCPhase(angle, dim=4, wires=[1, 2, 3])`.
4. **Linear Combination of Unitaries (LCU)**:
   A single QSVT sequence implements $P(A) + i Q(A)$, where $Q(A)$ is the complementary polynomial.
   To extract **only the real part** $P(A) \approx C A^{-1}$, we use an LCU ancilla qubit (`wire 0`):
   $$\frac{U_{\text{QSVT}} + U_{\text{QSVT}}^\dagger}{2} = P(A)$$
   When wire 0 and wire 1 are in state $|0\rangle$, the output state is strictly proportional to $A^{-1} b$ without any complementary imaginary component.
